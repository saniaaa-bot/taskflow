# TaskFlow - Personal Task Management System

A modern, responsive full-stack task management application built with Laravel, Tailwind CSS, and SQLite. It helps users organize their daily tasks efficiently.

## 🚀 Features
- **CRUD Operations:** Create, Read, Update, and Delete tasks.
- **Status Toggle:** Mark tasks as Pending or Completed with a single click.
- **Responsive Design:** Fully functional and beautiful on desktop and mobile devices.
- **Validation:** Server-side validation with elegant error messages.
- **Confirmation Dialog:** Prevent accidental task deletions.

## 💻 Tech Stack
- **Backend:** Laravel 12 (PHP 8.2)
- **Frontend:** Blade Templates, Tailwind CSS, Vanilla JS
- **Database:** SQLite
